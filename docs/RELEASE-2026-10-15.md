## Cloud saving

Signed-in accounts now save changed progress, challenge drafts, form controls/code, extra C# solution files and terminal sources automatically. Work is checked every five seconds while visible and online; unchanged work produces no write. First save requires no opt-in button. A fresh device restores the last snapshot automatically. Conflicting local/cloud edits pause saving and preserve local work until the learner chooses in Account → Cloud recovery & save options. Manual recovery remains available there; Sign out remains a normal account action.

Initial cloud reads cannot overlap. Failed connections retry with backoff rather than polling every five seconds. Snapshot revisions prevent two devices silently overwriting one another. Browser closure before a pending save finishes can still leave the most recent edits only on that device: the status states when saving has finished. The server enforces its existing 1 MiB snapshot limit; oversized work stays local and can be exported. This is snapshot synchronization, not simultaneous collaborative editing.

## Console challenges and performance

`#challenges/console` offers beginner greeting, sum/validation and countdown repairs with real C# test cases and persistent drafts. The console accepts a value at each ReadLine prompt, supports blank input, EOF and Stop, and displays compiler errors. The repair lab also offers this console for its current program. The browser runtime replays the source with accumulated input after each answer; it does not hold a live .NET stdin process. Time/random/file side effects can change across replays; use deterministic console programs or buffered runs for these cases. Recorded repair traces remain replay snapshots, not a live Visual Studio debugger.

The compiler reuses its compilation object for subsequent runs. Its startup preparation and execution safety limits remain. Cloud code imports lightweight form validation instead of loading the whole WinForms designer. The beginner console is a separate lazy-loaded route.
